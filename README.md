# ai-godot-generate

- `web/`：**Asset Forge 遊戲素材工坊**，產生 VFX、角色 sprite sheet、地圖圖塊，並輸出 Godot 4 檔案。說明見 [web/README.md](web/README.md)。
- `third_party/`：使用的開源專案（保留各自授權），清單見 [third_party/README.md](third_party/README.md)。
- `third_party/reference/`：參考用的開源專案，清單見 [third_party/reference/README.md](third_party/reference/README.md)。
